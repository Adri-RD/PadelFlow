# PadelFlow — Gestión de reservas de pádel

Proyecto Intermodular - Grado Superior DAM 2025/2026

## Tecnologías
- Backend: Java 17 + Spring Boot 3.3
- Base de datos: MySQL
- Frontend: HTML5 + CSS + JavaScript

## Cómo ejecutar
1. Crear la base de datos con el script `database/database.sql`
2. Copiar `application.properties.example` a `application.properties` y configurar la BD
3. Ejecutar el proyecto desde IntelliJ con `PadelApplication.java`
4. Abrir `frontend/index.html` en el navegador
